## Purpose

This lab is **not trying to be timeless**. It is tuned to stay **relevant for ~5 years**
(through ~2031) by separating:

| Layer | Lifespan | Examples |
|-------|----------|----------|
| **Durable contracts** | 5+ years | check→exploit→verify→cleanup, harness-first, evidence markers, scope gates |
| **Horizon domains** | 2–5 years | AI/agent security, identity-first cloud, supply chain, post-quantum prep |
| **Volatile tactics** | months–2 years | Specific CVE PoCs, tool flags, bypass strings, product versions |

**Rule:** Put durable rules in docs `00–19`. Put time-bounded bets in **this doc (`20`)**.  
Pin product versions only inside PoC harnesses — never as eternal agent dogma.

---

## Design Principles (Keep These Stable)

1. **Lab-contained by default** — Docker/VM/kind/LocalStack; no prod tenants.
2. **Full-attack packages** — README primary command is `--mode full`; CLI may default to `check`.
3. **Evidence or it didn’t happen** — `LAB_*` markers, JSON, optional pcap.
4. **ATT&CK as lingua franca** — techniques evolve; IDs remain the mapping layer.
5. **Red ↔ blue loop** — every invasive technique prefers a detection stub (`10`).
6. **Extension over rewrite** — new domain → new doc `2x` + template; don’t break `13`.
7. **Annual horizon review** — update this file each September (or after major platform shifts).

## Volatile vs Durable — Agent Behavior

When generating code through 2031:

| Do | Don’t |
|----|-------|
| Pin **vulnerable versions in harness** `package.json`/`pom.xml` | Hardcode “always exploit Next 15.0.0” in agent doctrine |
| Cite CWE + ATT&CK | Treat a single blog bypass as universal |
| Prefer protocol-level flaws (allowlist, authz, deserialize) | Depend on one WAF fingerprint forever |
| Design PoCs for **harness replay** | Assume internet C2 infra |
| Add `analysis/HORIZON.md` if technique is bleeding-edge | Claim timeless completeness |

## AI / Agent Security (P0 Focus Through 2031)

Threat classes to support by default:

- Direct / indirect **prompt injection**
- **Tool / MCP abuse** (unauthorized tool call, path traversal via args)
- **RAG data poisoning** / retrieved content injection

- Agent **loop / spend abuse** (lab cost markers)
- Multi-agent **confused deputy**

Package contract: same as `13` — harness + `--mode full` + evidence marker  
(`LAB_AI_INJECT=...` / unauthorized tool proof).
